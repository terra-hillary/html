# Meu Portfólio - Evolução em Front-End 

Este repositório documenta a minha evolução prática no desenvolvimento web. 

#  Sobre o Projeto
O que começou como uma página única de testes em HTML evoluiu para um site estruturado com múltiplas páginas e navegação interna. O objetivo principal é consolidar na prática os conceitos teóricos de estruturação e estilização web.

# Novas Atualizações
- **Navegação Integrada:** Criação de um menu principal (`index.html`) com links direcionando para páginas secundárias (`html.html`, `css.html`, `javascript.html`).
