#Meu Portfólio - Primeiros Passos em HTML 

Este repositório guarda a minha primeira página web construída do zero. 

## Sobre o Código
O arquivo `index.html` contém a estrutura básica de um documento web e inclui anotações de estudo nos comentários do código 

 Tecnologias e Tags exploradas
- Estrutura padrão do HTML5 (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Configurações de metadados (`<meta charset="utf-8">`)
- Tags de texto e títulos (`<h1>`, `<p>`, `<br>`)
*Este projeto será atualizado continuamente ao longo da graduação*
