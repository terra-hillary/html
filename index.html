Em Html existe uma estrutura básica formada atraves das tags <html>, <head> e <body>.

<html>: É a tag principal. Ela contém todo o código referente a página

<head>: É a parte que guarda as informações invisíveis para o usuário.

<body>: É o corpo da página. Onde se insere todos os dados ( textos, imagens, botões e vídeos ) que vão aparcer na tela
